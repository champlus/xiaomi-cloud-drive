# 使用米盘

米盘将小米云服务中的云盘挂载到 macOS Finder。

## 登录与挂载

打开米盘，在小米官方页面完成登录，然后点击「Finder → 打开」。Finder 侧边栏显示 `MiCloud.local`，卷名为「小米云盘」，挂载位置是个人文件夹下的「小米云盘」。

拖入文件即可上传，打开文件时按需下载。重命名、移动、创建文件夹和删除都可以在 Finder 中完成。删除的云端文件会进入小米云盘的「最近删除」。

## 设置

- **云盘**：连接状态、Finder 入口、小米账号和网页版。
- **通用**：登录时启动、自动挂载、只读访问。
- **传输**：最近记录和未完成传输的本地副本。

关闭设置窗口后，米盘继续运行。需要退出时，从菜单栏选择「退出米盘」。

## 常见问题

### 首次打开被 macOS 拦截

当前下载包使用本地签名。可在「系统设置 → 隐私与安全性」中选择允许打开。

### 文件夹里的内容没有立即更新

目录会短暂缓存。可在「云盘」中点击刷新，或运行 `mipan refresh`。

### 会自动同步本地文件夹吗

米盘提供在线挂载。文件在打开时下载，拖入时上传，不做本地文件夹的持续同步。

### 空文件和大文件

小米接口不接收零字节文件，因此空文件先保存在本机，写入内容后才上传。单文件需小于 4 GiB。

### 登录过期

米盘会定时通过小米官方页面续接登录；请求遇到认证失败时，先显示「恢复连接中」，后台恢复后自动重试一次。网络错误、请求限流和云空间已满不会当作登录过期。

登录及续接会话保存在 macOS 钥匙串，登录网页使用内存存储，不保存小米密码。会话更新后保留小米给出的有效期，重启 App 后继续使用。旧版网页和后台会话会合并迁移到统一的钥匙串条目。只有原生 App 读取钥匙串，后台服务使用内存会话。 更新安装只替换 App，沿用同一钥匙串条目，不清除登录状态；主动退出账号才清除会话。

若显示「需要验证」，在「云盘」中点击登录，在官方页面完成验证。小米主动撤销登录、更改密码或要求安全验证时仍需手动认证，客户端不能承诺固定的免登录月数。

## 本机数据

设置、目录元数据和未完成上传的副本位于 `~/Library/Application Support/米盘/`。自动启动项位于 `~/Library/LaunchAgents/dev.cham.midrive.plist`。

本地连接仅使用回环地址，不修改 hosts 或系统路由。

### 钥匙串授权

固定证书签名的更新沿用相同应用身份。旧版使用临时签名，首次迁移其独立保护的条目时，macOS 可能要求确认；在「云盘」中点击「授权钥匙串」进行迁移。新版后台读取失败只显示需要授权，不会自动弹出系统密码框。主动退出账号会清空统一存储，后续启动不会重新导入旧会话。
