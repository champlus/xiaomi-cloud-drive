# 体验核实记录 · 2026-10-29

本轮修复了实际代码更新后反复需要钥匙串确认的问题、启动台保留橙色旧图标的问题，以及目录缓存、状态一致性和请求退避问题。本轮修复对应 v0.1.2，下载包与版本说明见 [GitHub Release](https://github.com/champlus/xiaomi-cloud-drive/releases/tag/v0.1.2)。

## 登录与升级

旧方案使用固定自签名证书，但实际钥匙串条目还具有旧可执行文件 CDHash 的分区限制；相同证书和 designated requirement 不能替代实际访问验收。两个代码不同的模拟 App 直接读取旧方式保存的模拟条目时，第二版返回 `-25293`。仅查阅真实条目的访问控制元数据，没有输出登录内容。

新版把会话保存在固定凭证组件拥有的新钥匙串条目中。组件验证真实父进程的 App 标识和证书，App 在传递会话前验证正在运行的组件。组件不接受任意服务名或账号，不通过参数、环境变量、文件或日志传递会话，只通过经过验证的父子进程管道传输。正常钥匙串读写在后台执行，具有超时；新版和空退出记录都优先于旧条目，不会重新导入已退出的旧会话。

模拟测试在本机默认登录钥匙串中创建唯一命名的测试条目，覆盖首次写入、读取、两个不同代码哈希 App 之间的继承、未授权父进程拒绝、伪造子组件拒绝与测试条目清理，全程没有云端请求。首次写入不需要用户点击迁移按钮。旧版已有条目仍受 macOS 原有访问控制约束；用户已完成恢复，迁移后没有重新登录小米。

真实账号随后通过两次实际不同的 App 更新验证：第一轮修改登录恢复界面和管道处理代码，确认界面可执行文件内容变化、凭证组件内容不变；第二轮更新图标资源查找代码和 CFBundleVersion（2 → 3）。两轮都自动恢复连接和 Finder 挂载，没有再次要求系统密码或打开小米登录窗口。最终本地状态为 connected=true、hasSession=true、authRequired=false，且无待恢复传输。

发布构建固定复用同一签名凭证组件，源码与二进制校验值记录在 `native/credential-helper.json`。同一发布身份出现不匹配会中止构建，不能通过重新编译、重新签名组件默默破坏已有用户的授权。更换发布机器必须保留原签名组件缓存。未经过真实的一两个月等待，不能把模拟长期恢复和两次实际升级说成已完成一两个月在线续期验收；小米仍可要求账号验证。

## 图标与启动台

原构建复制预先生成的旧 ICNS，运行中又用没有留白的 PNG 覆盖图标。现改为从用户提供的 `macos/AppIcon.png` 生成所有标准尺寸的 ICNS，图案占画布 80%，居中、四边透明。运行中的 App、安装包和 Finder 使用 Info.plist 指定的同一资源。

另行核对发现，启动台的米盘条目仍缓存橙色白方块旧图。回归测试先失败（归一化像素差 0.309），随后改用包含图案与生成脚本内容摘要的图标文件名，安装时刷新 Launch Services 登记，并在本机重启 Dock 以更新已有缓存。测试随后通过（像素差 0.004）。启动台条目 ID、父目录和排序仍为 578、64、34，未重置分组或排序；读取缓存确认现在为缩放后的蓝色云朵。

## 加载、一致性和请求密度

| 项目 | 修复和验证 |
| --- | --- |
| 状态一致性 | 菜单栏和设置页共用状态文案；本机尚未载入凭证不再被 CLI 误报为小米登录过期。 |
| 缓存失效 | 失效后新请求不再等待或复用旧的在途目录列表；旧请求不能写回新缓存。 |
| 刷新失败 | 同目录失败按 5–60 秒退避，已有缓存仅在原有效期内使用；显式失效清除退避。 |
| 云端目录索引 | 操作后从 200ms 起退避查询，上限 1 秒；650ms 模拟延迟的查询数从 7 次降至不超过 3 次。 |
| 限流 | 403/429 后跨目录暂停 API，默认 60 秒，遵守 Retry-After；不当作认证失败反复续期。仅在本地模拟限流。 |
| 登录请求量 | 保存的会话恢复成功后不立即额外访问登录页，短暂唤醒不强制续期。 |

真实账号验收只运行一轮，在独立目录 `/米盘体验核实-20261029-<随机后缀>` 使用一个小文本文件，顺序操作、每步间隔 2 秒、遇错即停。所有操作成功，测试目录已移入云端最近删除，未触碰用户材料。

| 验收操作 | 本轮耗时 |
| --- | ---: |
| 首次读取空测试目录 | 111 ms |
| 缓存读取相同目录 | 15 ms |
| 小文本文件上传 | 912 ms |
| 上传后目录读取 | 184 ms |
| Finder 挂载路径读取并完成 SHA-256 比对 | 790 ms |

这些是单次小目录和小文件样本，不能代表大目录、大文件或复杂网络条件。测试没有触发真实限流，没有注入登录失败或进行压力测试。
